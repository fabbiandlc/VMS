# Velocity Motorsport Series

Download the code, open it in VS Code, and run it with Live Server to make local improvements.

## Getting started

1. Download or clone this project.
2. Open the folder in VS Code.
3. Open `index.html`.
4. Right-click the file and select "Open with Live Server".
5. If you do not have the Live Server extension, install it from VS Code Extensions.

## Basic structure

- `index.html` — main page
- `js/` — project scripts
- `neon.ts` — Neon service configuration for Postgres and Object Storage
- `tools/` — utilities for generating or extracting content

## To improve the project

- Edit the HTML, CSS, and JavaScript files directly.
- Test your changes with Live Server.
- If you want to connect real Neon data, check the configuration in `js/vms-config.js` and the linked project in `.neon`.

## Recommended workflow

For quick development and testing:

- open the folder in VS Code
- run it with Live Server
- save the file and reload the page to see the changes
